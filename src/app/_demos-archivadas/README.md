# Demos archivadas

Las 9 demos anteriores (y `api-asesoria-emails`, su API) se conservan aquí pero **no se sirven**: la carpeta empieza por `_`,
así que Next no la enruta. Para reactivar una, moverla a `src/app/demos/<slug>/` (la API, a `src/app/api/demos/asesoria-emails/`)
y recuperar su tarjeta en `src/app/demos/page.tsx`. La demo vigente es `src/app/demos/agentes/`.
